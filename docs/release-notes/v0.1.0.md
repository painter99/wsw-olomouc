# WSW Olomouc v0.1.0

First stable line — a personal weather app for Olomouc built on direct measurements from local stations.

## Highlights
- Primary source: infopocasi-olomouc.cz (data used with the station operator's consent)
- Secondary/fallback: CHMU Olomouc–Holice open data (CC BY 4.0)
- Home screen widget with freshness-weighted synthesis of both stations
- Temperature trends (app 1/3/6 h windows, widget 90 min)
- Per-source status and persistent rate limiting (1 request / 10 min / source)
- Local history (Room, 72 h retention) — no backend, no accounts, no tracking
- 153 unit tests green

## Install
Debug-signed sideload build — enable "install unknown apps" for your browser or file manager, then install the APK.
